# Battleship

**Battleship** — это консольная реализация классической морской битвы на языке C++. Поддерживается игра между двумя игроками или между игроком и ботом.

## 📦 Возможности

- Отрисовка поля и кораблей в консоли
- Управление вводом/выводом
- Простая и расширяемая архитектура
- Поддержка игры против бота
- Модульные тесты (через GoogleTest)

## 🛠️ Сборка

### Зависимости

- CMake ≥ 3.13
- Компилятор с поддержкой C++20 (например, `g++`, `clang++`)
- (Для тестов) GoogleTest

### Сборка проекта

```bash
git clone https://github.com/tonmalanin/battleship.git
cd battleship
chmod +x build.sh
./build.sh
```

### Запуск

```bash
./bin/battleship.exe
```
